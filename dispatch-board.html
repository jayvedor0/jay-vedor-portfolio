Dispatch rules

Assign by area first, then by workload, so no tech crosses town between back-to-back jobs.

Every customer gets a reminder an hour before the window and a text with a new ETA if a tech is running more than 30 minutes late.

  1. See the whole day

    Every job, window, tech, and status in one list instead of across calls, texts, and a calendar.

  2. Fix problems first

    Unassigned, late, and reschedule jobs are the default view, because they are the ones a customer will call about.

  3. Keep customers informed

    Each row carries the next customer touch, from reminder calls to new ETAs, so nobody is left waiting without an update.
